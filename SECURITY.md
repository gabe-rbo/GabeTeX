# Security Policy

GabeTeX is split into one repository per platform. Security reports go to the repository of the app that is affected,
using GitHub's private vulnerability reporting (**Security** tab > **Report a vulnerability**):

- macOS: [GabeTeX-macOS](https://github.com/gabe-rbo/GabeTeX-macOS/security)
- Linux: [GabeTeX-Linux](https://github.com/gabe-rbo/GabeTeX-Linux/security)
- Windows: [GabeTeX-Windows](https://github.com/gabe-rbo/GabeTeX-Windows/security)

If you are not sure which one applies, or the problem concerns the website, report it privately in this repository's
[Security tab](https://github.com/gabe-rbo/GabeTeX/security).

Please do not report security problems in public issues, pull requests or discussions.

## Supported versions

Only the latest release of each app receives security fixes. Check that the problem happens on the latest release
(for macOS, see the [Releases page](https://github.com/gabe-rbo/GabeTeX-macOS/releases/latest)).

## What to include

- The app and its version, plus your operating system version
- What the problem is, and what someone could do with it
- Steps to reproduce it, plus a minimal project or file if one is needed
- Any proof-of-concept code, with a short note on what it does

## What to expect

The maintainer aims to acknowledge a report within 7 days and will keep you informed while the problem is
investigated and fixed. GabeTeX is maintained by one person in their spare time, so please allow for some delay.
